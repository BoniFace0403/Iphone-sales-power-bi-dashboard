# Iphone-sales-power-bi-dashboard
A Power BI dashboard exploring iPhone sales by model, country, and month, with an accompanying project report.

## Project files

- [Download the Power BI dashboard](./iphones.pbix)
- [Read the iPhone sales report (PDF)](./Iphone%20sales%20report%20velocity.pdf)
- ## Dataset

[View or download the iPhone sales dataset (CSV)](./iphone_sales_dataset.csv)

The dataset contains 100 sales records across six iPhone models and six
countries, covering 1 January to 1 May 2025. May is a partial month.
